# NicheSpy — SPEC.md ## 1. Concept & Vision NicheSpy is a competitor analysis weapon for YouTube and TikTok creators. Drop any channel URL and get back a full intelligence report: top-performing content, winning keywords, audience demographics, and content gaps — in under 30 seconds. The brand feel is bold, data-driven, and slightly cyber/hacker-adjacent — like a private intelligence tool that happens to be for creators. The tagline: "Spy on any channel in 30 seconds." --- ## 2. Design Language ### Aesthetic Bold + dark + data-intelligence. Think mission control meets creator studio. Sharp edges, tight spacing in hero, generous padding in feature grids. Not aggressive — precise. ### Color Palette ``` --bg: #030712 (near-black background) --surface: #0f172a (card/surface background) --border: #1e293b (subtle borders) --primary: #8b5cf6 (violet — insight/intelligence) --secondary: #06b6d4 (cyan — data/tech) --success: #10b981 (green — growth/positive) --text: #f9fafb (near-white text) --muted: #6b7280 (gray — secondary text) ``` ### Typography - Font: **Inter** (Google Fonts) - Headings: bold, large (hero 64px, sections 40px+) - Subheadings: semibold, medium - Body: regular, 16-18px ### Motion Philosophy - Entrance: fade + translateY(-12px), 400ms ease-out, staggered 80ms between items - Hover: subtle scale(1.02) + box-shadow lift, 200ms ease - Buttons: slight glow on hover via box-shadow - Loading animation: pulsing skeleton cards --- ## 3. Layout & Structure ### Page Sections (top to bottom) 1. **NavBar** — sticky, blurred backdrop, logo left, nav links center, CTA right 2. **Hero** — full-viewport-height, centered, headline + sub + search demo 3. **Search Demo** — mock live demo with loading state + result preview card 4. **Features Grid** — 6-card bento grid (2 rows × 3 cols) 5. **How It Works** — 4 horizontal steps with connecting line 6. **Stats Bar** — dark strip with 3 big numbers 7. **Testimonials** — 3-card row 8. **Pricing** — 3-column pricing cards 9. **CTA** — centered conversion section 10. **Footer** — links + social + legal ### Responsive Strategy - Mobile-first with breakpoints at 640, 768, 1024, 1280px - Navbar collapses on mobile (hamburger menu) - Grid cards stack to 2-col then 1-col - Pricing cards stack vertically on mobile --- ## 4. Features & Interactions ### Search Demo (Mock) - Input: placeholder "Enter any YouTube channel URL" - Button: "Analyze" with violet gradient - On click: simulates 2s loading (skeleton pulsing) - After loading: reveals a mock result card showing: - Channel name + handle - 3 top videos with titles and view counts - Top 3 keywords - Audience demographics pie chart (CSS-only representation) - Content gap suggestions ### NavBar - Logo: eye-icon + "NicheSpy" wordmark - Mobile: hamburger toggles a slide-down menu - Active link highlighting on scroll ### Pricing Cards - Starter ($19): 5 channels/mo, email support, basic reports - Growth ($49): 25 channels/mo, gap analysis, priority support - Pro ($99): unlimited, API access, CSV export, dedicated support - "Most Popular" badge on Growth card - Hover: border glows with primary color ### Interactions - All buttons: hover glow effect - Feature cards: hover lifts with shadow - Testimonial cards: subtle hover scale - Pricing cards: hover border highlight --- ## 5. Component Inventory ### NavBar - Sticky top, backdrop-blur, border-bottom - Logo (SVG eye icon + text) - Desktop nav links (How It Works, Use Cases, Pricing, Login) - CTA button: "Try Free" (violet gradient) ### Hero - Large headline: "Know exactly what's working for any creator" - Subtext: "Paste a channel URL. Get a full intelligence report in 30 seconds." - Search Demo component below ### SearchDemo - States: idle → loading → results - Input + button form - Result card (shown after "loading") ### FeatureCard - Icon (Lucide), title, description - Surface background, border, rounded-xl ### HowItWorksStep - Number badge, title, description - Connected by dashed line on desktop ### StatsBar - Dark surface strip - 3 stat items: big number + label ### TestimonialCard - Avatar placeholder, name, handle, quote text - Star rating (5 stars) ### PricingCard - Plan name, price, feature list, CTA button - Popular badge variant for Growth tier ### Footer - Logo, tagline - Link columns: Product, Resources, Company, Legal - Social icons: Twitter, YouTube, TikTok --- ## 6. Technical Approach ### Stack - **Next.js 15** App Router (TypeScript) - **Tailwind CSS v4** — `@import "tailwindcss"` + `@theme {}` block - **Lucide React** — icons - **Inter** from Google Fonts ### Architecture - Single-page landing: `app/page.tsx` - Components in `app/components/` - CSS in `app/globals.css` - No backend — static marketing page ### Files ``` niche-spy/ ├── SPEC.md ├── package.json ├── next.config.js ├── tsconfig.json ├── postcss.config.js ├── tailwind.config.ts (not needed for v4, use CSS @theme) ├── .gitignore ├── public/ │ └── (empty — no assets needed) └── app/ ├── globals.css ├── layout.tsx └── page.tsx ``` ### Deployment - `npx vercel --yes --token ""` - Production URL captured after deploy
